# Навчання 🌸

Маленький додаток для навчання: розклад занять, завдання з дедлайнами, графіки прогресу й нагадування. Зібрано для магістратури ХНУ ім. Каразіна і курсу «Військовий психолог» УКУ.

Працює як сайт і як додаток на телефоні: відкрий сайт у браузері й обери «Додати на головний екран».

## Як оновити дані

Усе лежить у `data/data.json`: предмети, заняття (`events`), завдання (`tasks`) і важливі дати (`milestones`). Після змін запусти

```
python3 tools/make_ics.py
```

щоб оновити `calendar.ics`, на який можна підписатися в Google Календарі.

Статуси завдань, власні завдання й посилання на Zoom зберігаються лише на твоєму пристрої. Посилань на Zoom і паролів у репозиторії немає.
